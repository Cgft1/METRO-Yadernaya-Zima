# METRO: Ядерная зима — Minecraft Forge 1.20.1

## Прототип
- Предметы: консервы, фильтр, аптечка, противогаз и металлолом.
- Радиация: в Верхнем мире выше Y=62 игрок получает 1 урон каждые 5 секунд, если не держит противогаз в руке или второй руке.
- Тоннельный мутант: повышенное здоровье, скорость и урон, атакует игроков.

## Сборка
GitHub Actions автоматически собирает мод при каждом push в main и по ручному запуску workflow. Готовый JAR будет доступен в разделе Actions как артефакт сборки.

## Ограничения прототипа
Пока нет генерации метро, пользовательских моделей и текстур, полноценного расходования фильтров и лечения аптечкой. Противогаз защищает, если находится в руке.
